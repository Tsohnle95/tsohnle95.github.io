Luno Mobile

Local music, built for Android

Bring Luno's local music experience to Android while respecting platform storage, playback and background-work behaviour.

What it does

  • Native interface. Compose provides the Android interface.
  • Durable library. Room persists the local music collection.
  • Native playback. Media3 manages playback.
  • Background downloads. WorkManager handles downloads within Android’s background-work model.

A native Android build using Compose for the interface, Room for durable library state, Media3 for playback, and WorkManager for downloads.
