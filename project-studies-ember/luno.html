Luno

A music library on your own machine

Build a capable music player around a local library, without making playback, downloads, playlists or discovery depend on a cloud account.

What it does

  • Local library. Build a collection without depending on a cloud account.
  • Playback and playlists. Listen to your library and organise it into playlists.
  • Downloads and discovery. Bring downloads and music discovery into the same desktop experience.
  • Native application layer. A Tauri/Rust layer supports a React and TypeScript interface, with boundaries for playback and persistence.

An AI-assisted build across a React and TypeScript interface and a native Tauri/Rust layer, with clear boundaries for playback, persistence, downloads and discovery.
